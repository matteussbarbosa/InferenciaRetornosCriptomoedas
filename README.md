# Cryptocurrency Return Inference

## Overview

This project applies statistical methods to historical cryptocurrency market data to analyze **logarithmic returns** and estimate **confidence intervals for average returns**.

Historical price data is obtained through the **Binance API** and processed using Python.

## Objectives

* Retrieve historical cryptocurrency price data.
* Calculate logarithmic returns.
* Analyze return distributions.
* Estimate confidence intervals for average returns.
* Apply statistical inference to cryptocurrency market data.

## Technologies

* Python
* Binance API
* Statistical Analysis
* Data Analysis
* Logarithmic Returns
* Confidence Intervals

## Methodology

The analysis follows these main steps:

1. Retrieve historical cryptocurrency prices through the Binance API.
2. Process and prepare the price data.
3. Calculate logarithmic returns.
4. Estimate the average return.
5. Calculate confidence intervals for the estimated mean.
6. Interpret the statistical results.
